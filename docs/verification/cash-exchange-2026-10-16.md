# 공동 현금 환전 — 2026-10-16

사용자 결정: 남은 달러·현지 통화별로 각자 받을 금액을 표시한다.

- 앱에서 실제 건넨 현금과 수수료 차감 후 받은 현금을 입력한다. 환전은 지출/개인 입금으로 중복 계산하지 않는다.
- 통화별 잔액과 개인 몫을 시간순으로 재생한다. 일부 환전, 반복·역환전, 음수 분담채무, 통화 최소 단위 반올림을 보존한다. 원화는 저장된 취득원가로 계산한 참고치다.
- 웹은 동일 계산으로 읽기만 제공한다. 서버 미적용 때 기존 지갑은 계속 읽고 환전 입력을 숨긴다. 권한/네트워크 오류는 미적용으로 숨기지 않는다.
- SQL: 한 행에 양쪽 통화를 저장한다. 여행별 advisory lock, RLS, 통화 정밀도, 현금 잔액 검증. 클라이언트 요청 UUID를 재사용해 응답 유실 시 중복 환전을 방지한다.
- 환전 이후 과거 공동 지출/분담자 수정·삭제는 차단한다. 환전 취소·장부 정정 UI는 아직 없다.

검증: 양쪽 TypeScript 통과. 앱 `check-cash-exchange.cjs`(100개 반올림 사례, 재환전, 반환), `check-expense-wallet.cjs` 통과. `scripts/check-cash-exchange-db.cjs`를 PGlite 설치 환경에서 실행하여 실제 마이그레이션/입금/환전/지출/반환/권한/과거 변경 차단 통과. 동시 다중 DB 연결 경쟁과 실서비스 API는 미검증.

웹 실제 CashWalletView 컴포넌트를 합성 데이터로 번들하여 헤드리스 Chrome에서 표시 확인: 3명 각100 USD 입금 → 150 USD를3,750,000 VND로 환전 → 1,500,000 VND 지출 → 각50 USD 및750,000 VND 반환 몫. 운영 데이터는 변경하지 않았다.

미배포: `20261016002030_cash_wallet_exchange.sql` 운영 적용 전. 기존 앱은 환전 테이블을 모르므로 구버전 사용자가 남은 상태에서 환전을 활성화하지 말 것. 최소 지원 버전/업그레이드 정책과 웹·앱 동시 반영을 먼저 검증할 것. 카드 매칭 등 기존 미배포 변경이 있으므로 저장소 전체 무조건 배포 금지. iOS/Android 화면·키보드 실기기 검증 및 새 빌드는 남음.
